# Лавка — онлайн магазин

Уеб приложение за квартален магазин с каталог, търсене, категории, сортиране, количка и демонстрационна форма за поръчка.

## Стартиране

Отвори `index.html` в браузър. Не са нужни инсталации или сървър. За локална разработка може да използваш Live Server във Visual Studio Code.

## Функционалности

- Адаптивен дизайн за телефон, таблет и компютър.
- Търсене на продукти с клавишна комбинация `Ctrl/Cmd + K`.
- Филтриране по категории и сортиране по цена.
- Количка с добавяне, премахване и промяна на количеството.
- Количката се запазва в браузъра чрез `localStorage`.
- Демо форма за поръчка; плащане и реална доставка не се обработват.

## Файлове

- `index.html` — структура и съдържание.
- `styles.css` — стилове и адаптивен изглед.
- `app.js` — каталог и интерактивност.
